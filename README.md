# 📚 Aulas & Exercícios Práticos

Este repositório reúne os materiais de estudo, códigos de aulas práticas e atividades focadas nos fundamentos e evolução do desenvolvimento web.

---

## 📌 Conteúdos do Repositório

- **Aulas Teóricas e Práticas:** Códigos desenvolvidos durante o acompanhamento das aulas (como introdução ao JavaScript e integração com HTML).
- **Atividades Práticas:** Exercícios fixadores para colocar em prática a lógica de programação e conceitos web.
- **Mídia & Recursos:** Organização de imagens e ativos utilizados nos exercícios práticos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação de páginas para a web.
- **JavaScript (ES6+):** Lógica de programação e manipulação de scripts.
